# Portfolio Evrard AYIDEDJI

## A propos

Ce portfolio professionnel presente le parcours, les competences et les projets d'Evrard AYIDEDJI, etudiant en Licence Mathematiques & Applications passionne par le developpement web, la cybersecurite et l'innovation technologique.

## Technologies utilisees

### Frontend
- HTML5 - Structure semantique du site
- CSS3 - Styles modernes avec variables CSS, animations et design responsive
- JavaScript (ES6+) - Interactions dynamiques, animations et gestion des evenements

### Bibliotheques et ressources externes
- Font Awesome 6 - Icones vectorielles
- Google Fonts - Polices Inter et Space Grotesk
- Formspree - Gestion des formulaires de contact

## Structure du projet
├── index.html # Page d'accueil avec presentation
├── competences.html # Page des competences techniques
├── projets.html # Page des projets et objectifs
├── parcours.html # Page du parcours academique
├── contact.html # Page de contact avec formulaire
├── styles.css # Feuille de style principale
├── main.js # Scripts JavaScript globaux
└── img.jpg # Image de profil


## Fonctionnalites

### Animations et interactions
- Canvas de particules - Animation de fond dynamique avec particules flottantes
- Loader de chargement - Animation de progression 0% a 100% avec cercle de progression personnalise
- Animations au scroll - Apparition progressive des elements via Intersection Observer
- Barres de competences - Animations de progression declenchees au declenchement

### Navigation
- Menu responsive avec affichage mobile
- Liens actifs mis en evidence automatiquement selon la section visible
- Fermeture automatique du menu mobile apres selection

### Formulaire de contact
- Validation cote client
- Envoi asynchrone via Formspree
- Feedback utilisateur en temps reel

## Responsive Design

Le site est entierement responsive avec des points de rupture adaptes aux ecrans mobiles, tablettes et ordinateurs de bureau. Le menu de navigation se transforme en menu hamburger sur les petits ecrans.

## Performance

- Animations optimisees avec requestAnimationFrame
- Chargement progressif des elements via Intersection Observer
- Transition fluide du loader vers le contenu principal
- Canvas de particules leger avec nombre limite de particules

## Compatibilite

Teste sur les navigateurs modernes :
- Chrome / Edge
- Firefox
- Safari
- Opera
